# کلاغ — پروژهٔ Android Native

این پوشه پروژهٔ اندرویدی بازی «کلاغ» است. برنامه از `WebView` استفاده نمی‌کند و هیچ صفحهٔ HTML را در مرورگر داخلی نمایش نمی‌دهد.

## ساختار اجرا

- **Activity و چرخهٔ فریم:** Kotlin و Android `View`
- **رندر گرافیک:** `android.graphics.Canvas` و `Bitmap`؛ تبدیل Canvas 2D به لایهٔ رسم Native داخل Kotlin انجام شده و بافر پیکسلی/نسبت تصویر اصلی حفظ شده است.
- **منطق بازی:** منطق صحنه‌ها، دیالوگ‌ها، معماها و مینی‌گیم‌های فایل اصلی در `app/src/main/assets/game.js` نگه داشته شده و داخل خود برنامه با موتور سبک Rhino اجرا می‌شود. کد به ES5 سازگار تبدیل شده تا روی Rhino اجرا شود؛ این موتور مرورگر نیست و هیچ WebView یا صفحهٔ وبی ساخته نمی‌شود.
- **اندازهٔ دنیای بازی:** ارتفاع ۱۸۰ پیکسل و عرض متناسب با نسبت تصویر، از ۳۲۰ تا ۴۳۲ پیکسل؛ روی نمایشگر افقی با مقیاس‌دهی مناسب نشان داده می‌شود.
- **صدا:** تولید Native با `AudioTrack`؛ افکت‌ها و حال‌وهوای محیطی بازسازی شده‌اند، اما شکل موج و میکس ممکن است دقیقاً مشابه Web Audio مرورگر نباشد.
- **ذخیرهٔ پیشرفت:** `SharedPreferences` به‌عنوان ذخیره‌ساز محلی بازی.
- **فونت‌ها:** فایل‌های اصلی `PlasmaDots` و `VazirSign` داخل assets قرار دارند.

## پیش‌نیازها

- Android Studio سازگار با Android Gradle Plugin 9.0.1
- JDK 17 یا بالاتر
- Android SDK Platform 36 و Build Tools 36.0.0
- اینترنت در اولین Gradle Sync برای دریافت Gradle، Android Gradle Plugin و کتابخانهٔ Rhino

## ساخت APK در ویندوز

۱. فایل ZIP را Extract کن.
۲. Android Studio را باز کن و پوشهٔ `CrowNativeAndroid` را با گزینهٔ **Open** انتخاب کن.
۳. در صورت درخواست، JDK 17 و Android SDK 36 را انتخاب/نصب کن و منتظر پایان Gradle Sync بمان.
۴. از منوی **Build → Build APK(s)** خروجی بگیر.

یا در PowerShell داخل ریشهٔ پروژه:

```powershell
.\gradlew.bat assembleDebug
```

فایل APK پس از ساخت در این مسیر خواهد بود:

```text
app\build\outputs\apk\debug\app-debug.apk
```

## کنترل‌ها

بازی در حالت افقی اجرا می‌شود. کنترل‌های لمسی، لمس چندگانه و دکمه‌های لمسی خود بازی فعال‌اند. کلیدهای جهت‌دار، Enter، Space، E، F، I، H، M و Escape نیز پشتیبانی می‌شوند. دکمهٔ Back اندروید ابتدا لایهٔ داخلی بازی را می‌بندد یا بازی را Pause می‌کند.

## نکتهٔ وفاداری تصویری

صحنه‌ها، شخصیت‌ها، متن‌ها، مراحل و منطق بازی از فایل ارسالی نگه داشته شده‌اند و خروجی روی Android Canvas ترسیم می‌شود. موتور اجرا و رندر/ورودی/صدا/ذخیره‌سازی Native هستند، اما منطق بازی هنوز بازنویسی ۱۰۰٪ Kotlin نشده و داخل Rhino اجرا می‌شود؛ این انتخاب برای حفظ رفتار نسخهٔ اصلی است. به‌دلیل تفاوت rasterizer فونت، ترکیب رنگ و افکت blur اندروید با مرورگر، ممکن است جزئیات بسیار ریز anti-aliasing یا میکس صدا دقیقاً پیکسل‌به‌پیکسل برابر نباشد. رزولوشن پیکسلی و محتوای بازی حفظ شده‌اند.

## وضعیت بررسی

سورس JavaScript پس از تبدیل به ES5 با بررسی نحوی Node.js کنترل شده است. ساخت APK در محیط آماده‌سازی اجرا نشد، چون Android SDK و پلتفرم Android در آن محیط نصب نبودند و دسترسی شبکه برای دریافت Gradle نیز فراهم نبود؛ بنابراین خروجی APK و اجرای نهایی روی دستگاه هنوز باید با Android Studio بررسی شود.
